# Aizvietošana

Lietotne aizvietošanas un papilddarbu sadalei brigādēm: darbu vadītāji piesaka darbus,
admins piešķir brigādes un publicē plānu, brigādes atzīmē izpildi ar bildēm.
Lietotni var pievienot iPhone sākuma ekrānam, un tā sūta paziņojumus.

Dati un loģika atrodas Google Apps Script / Google Sheets (`apps-script/Code.gs`) — šī lapa ir lietotnes saskarne.
Iestatīšana — `IESTATISANA.md`.
